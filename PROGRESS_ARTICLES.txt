=== SEO ET INDEXATION ===

  Point de depart : 3 pages indexees sur environ 24 articles.
  Causes identifiees et corrigees :
    - aucun sitemap.xml ni robots.txt n'existait
    - 8 pages n'avaient aucun canonical
    - deux articles (bons-tresor-canadiens, croissance-vs-dividendes) avaient un
      canonical pointant vers une URL repertoire inexistante : ils se declaraient
      doublons d'une page qui n'existait pas
    - les contenus EN et ES n'avaient aucune URL propre : ils etaient injectes par
      JavaScript sur l'URL francaise, donc invisibles pour Google

  En place aujourd'hui :
    - sitemap.xml         138 URL, lastmod tire de l'historique git
    - robots.txt          tout explorable, pointe vers le sitemap
    - _headers            X-Robots-Tag: noindex sur *.pages.dev et *.workers.dev
                          uniquement. Le domaine principal n'est jamais affecte.
    - canonical           sur les 138 pages indexables, tous resolus vers un fichier reel
    - hreflang            4 balises reciproques par page, x-default vers le francais
    - _redirects          redirection 301 active, dans les trois langues, de
                          /articles/quiz-frais-de-placement.html
                          vers /quiz/frais-de-placement/
                          (l'ancienne URL etait deja indexee : le referencement
                          acquis est transfere, pas perdu)

  Une seule page porte un noindex : /merci-infolettre/ (page de remerciement de
  l'infolettre). C'est voulu. Elle reste explorable pour que Google puisse lire
  ce noindex, et elle est exclue du sitemap.


=== OUTILS DE GENERATION ===

  tools/gen-i18n-pages.ps1
    Genere les pages EN et ES a partir du fichier FR reel et de translations.js.
    Ne fabrique aucun gabarit : il part du HTML existant, remplace le contenu de
    chaque element data-i18n, puis reecrit le head (title, description, Open Graph,
    Twitter, JSON-LD, canonical, hreflang) et les liens internes.
    Gere quatre familles d'URL :
      accueil    /                  -> /en/              | /es/
      section    /celi-reer/        -> /en/tfsa-rrsp/    | /es/celi-reer/
      article    /articles/x.html   -> /en/articles/y.html
      quiz       /quiz/x/           -> /en/quizzes/y/    | /es/cuestionarios/y/
    Une page sans bloc "METADONNEES SEO PAR LANGUE" complet est ignoree, jamais
    generee a moitie. C'est ce qui protege a-propos, dont les versions EN et ES
    sont ecrites a la main.

  tools/gen-sitemap.ps1
    Regenere sitemap.xml a partir des canonicals reels. Exclut les pages noindex.

  quiz.js
    Moteur de quiz partage, trois modes :
      "score"  : corrige et explique chaque reponse, bilan par paliers
      "profil" : aucune bonne reponse, cumul de points par profil, profil par
                 defaut en cas d'egalite
      "calcul" : chaque option verse des variables dans un accumulateur et peut
                 declencher une note conditionnelle. A la derniere question, le
                 moteur appelle la fonction calcul() fournie par la page, qui
                 renvoie { faible, min, max }. Le resultat est toujours une
                 fourchette, jamais un chiffre unique. Sous un seuil, un message
                 dedie remplace la fourchette : un "0 $" brut serait trompeur.
    Reprend exactement les classes CSS du quiz d'origine, sans styles inventes.

    Les 5 quiz :
      /quiz/combien-pour-la-retraite/  calcul  (8 questions)
      /quiz/abc-des-etf/               score   (20 questions)
      /quiz/profil-investisseur/       profil  (8 questions)
      /quiz/cote-de-credit/            score   (10 questions)
      /quiz/frais-de-placement/        score   (5 questions, moteur inline, voir phase 2)

    Prefixe des URL traduites : /en/quizzes/ et /es/cuestionarios/. Ne pas le
    changer sans redirections : ces URL sont declarees dans le sitemap soumis.

  Rappel technique : PowerShell 5.1 lit les .ps1 sans BOM en ANSI. Tout script
  contenant des accents doit etre enregistre avec un BOM UTF-8, sinon le HTML
  genere sort en mojibake.
